# Tech Stack: Nuxt (Vue)

## When to Use

- Vue ecosystem preference
- SEO-critical sites
- Full-stack Vue apps

## Setup

```bash
npx nuxi@latest init my-site
cd my-site
```

## Structure

```
pages/
├── index.vue
├── about.vue
└── blog/
    ├── index.vue
    └── [slug].vue
```

## Key Features

- File-based routing
- SSR + SSG
- Auto-imports
- Vue components
- Nitro server

## Deployment

- Vercel
- Netlify
- Node.js server
