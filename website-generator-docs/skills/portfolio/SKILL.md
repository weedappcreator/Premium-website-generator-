# Skill: Portfolio

## Purpose
Generate personal/portfolio sites showcasing work, skills, and experience.

## Structure

```
/
├── Hero (name, title, brief intro)
├── About (bio, photo, skills)
├── Projects/Work (grid of projects)
├── /project/[slug] (case study)
├── Experience/Timeline
├── Testimonials
├── Blog/Writing (optional)
└── Contact
```

## Design Principles

- **Visual-first**: Show work prominently
- **Minimal text**: Let projects speak
- **Personality**: Unique voice, not generic
- **Case studies**: Problem → Process → Result
- **Easy contact**: Clear CTA to reach out

## Project Card Format

- Title + thumbnail
- 1-sentence description
- Tags (tech, role, year)
- Link to live demo + code

## Technical Requirements

- Image optimization (critical for portfolios)
- Smooth animations (tasteful, not distracting)
- Dark mode option
- Fast load (under 1.5s)
- Social sharing (OG tags per project)
- Resume download (PDF)
