# Skill: Agency Site

## Purpose
Generate agency/consulting firm sites that showcase services and generate leads.

## Structure

```
/
├── Home
├── /services
├── /services/[service-slug]
├── /work (portfolio/case studies)
├── /work/[project-slug]
├── /about (team, values)
├── /blog
├── /careers
└── /contact
```

## Key Elements

- **Hero**: Clear positioning ("We help X do Y")
- **Services**: Detailed service pages with process
- **Case studies**: Before → After with metrics
- **Team**: Human faces build trust
- **Process**: How you work (discovery → delivery)
- **Client logos**: Social proof
- **Contact form**: Qualify leads with fields

## Lead Generation

- Contact form with qualification questions
- Calendar booking integration (Calendly)
- Newsletter signup
- Lead magnet (free audit, guide)
- Clear CTAs on every page
