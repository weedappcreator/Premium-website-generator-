# Skill: SaaS Product Site

## Purpose
Generate marketing sites for SaaS products with feature pages, pricing, and docs.

## Structure

```
/
├── Home
├── /features
├── /pricing
├── /docs (or link to external docs)
├── /blog
├── /changelog
├── /about
├── /contact
├── /login (link to app)
└── /signup (link to app)
```

## Key Sections

- **Hero**: Clear value proposition + free trial CTA
- **Feature grid**: Grouped by user benefit
- **Pricing**: 3 tiers (free, pro, enterprise) with comparison table
- **Social proof**: Logos, case studies, testimonials
- **Integration showcase**: "Works with your stack"
- **Security/Compliance**: Trust signals for enterprise
- **FAQ**: Address common objections

## SaaS-Specific Elements

- Free trial / demo CTA
- Pricing comparison table
- Feature comparison (free vs paid)
- Customer logos
- Case studies with metrics
- API documentation link
- Status page link
- Security page (SOC2, GDPR)

## Technical Requirements

- Blog with RSS
- Changelog page
- Schema markup (SoftwareApplication)
- Analytics + conversion tracking
- A/B test capable
- Fast TTFB (< 500ms)
