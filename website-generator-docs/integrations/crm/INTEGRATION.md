# Integration: CRM

## Options

### HubSpot
- **Best for**: All-in-one marketing + sales
- **Features**: CRM, email, forms, live chat, automation
- **Setup**: HubSpot JS snippet or API

### Pipedrive
- **Best for**: Sales pipeline management
- **Features**: Deals, contacts, activities, automation
- **Setup**: API or web forms

### Salesforce
- **Best for**: Enterprise, complex workflows
- **Features**: Everything, highly customizable
- **Setup**: API, complex

## Decision Guide

| Need | Choose |
|---|---|
| All-in-one marketing | HubSpot |
| Sales-focused | Pipedrive |
| Enterprise | Salesforce |
