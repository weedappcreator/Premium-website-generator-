# Integration: Social

## Social Sharing

### Share Buttons
```html
<!-- Twitter -->
<a href="https://twitter.com/intent/tweet?url=URL&text=TEXT">Share on X</a>

<!-- LinkedIn -->
<a href="https://www.linkedin.com/sharing/share-offsite/?url=URL">Share on LinkedIn</a>

<!-- Facebook -->
<a href="https://www.facebook.com/sharer/sharer.php?u=URL">Share on Facebook</a>
```

### Social Feeds

- **Instagram**: Embed widget or use Instagram API
- **Twitter/X**: Embed timeline or use API
- **LinkedIn**: Company page embed

### Social Proof

- **Testimonial.to**: Collect and display testimonials
- **Senja**: Video testimonials
- **TrustPilot**: Reviews widget

## Decision Guide

| Need | Choose |
|---|---|
| Share buttons | Native links (above) |
| Instagram feed | Embed widget |
| Testimonials | Testimonial.to |
| Reviews | TrustPilot |
