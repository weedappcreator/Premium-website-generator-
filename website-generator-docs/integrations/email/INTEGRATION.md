# Integration: Email

## Transactional

### Resend
- **Best for**: Next.js, developer experience
- **Setup**: `npm install resend`
- **Features**: React email components, templates

### SendGrid
- **Best for**: Scale, deliverability
- **Setup**: `npm install @sendgrid/mail`
- **Features**: Templates, analytics, suppression lists

## Marketing

### Mailchimp
- **Best for**: Email marketing, automation
- **Setup**: API or embed forms
- **Features**: Campaigns, segments, A/B testing

### ConvertKit
- **Best for**: Creators, newsletters
- **Setup**: API or embed forms
- **Features**: Sequences, tagging, landing pages

## Decision Guide

| Need | Choose |
|---|---|
| Transactional + DX | Resend |
| Transactional + scale | SendGrid |
| Email marketing | Mailchimp |
| Creator newsletter | ConvertKit |
