# Skill: Landing Page

## Purpose
Generate high-converting landing pages for products, services, or campaigns.

## Structure

```
/
├── Hero section (headline, subheadline, CTA)
├── Social proof (logos, testimonials, stats)
├── Features/Benefits (3-6 key points)
├── How it works (3-step process)
├── Testimonials/Reviews
├── Pricing (if applicable)
├── FAQ
└── Final CTA
```

## Best Practices

- **Above the fold**: Clear headline + single CTA
- **One goal per page**: Don't distract with multiple CTAs
- **Social proof early**: Logos, testimonials, trust badges
- **Benefits over features**: "Save 10 hours/week" not "AI-powered"
- **Scannable**: Short paragraphs, bullet points, visual hierarchy
- **Mobile-first**: 60%+ traffic is mobile
- **Fast load**: Under 2 seconds, optimize images

## Conversion Elements

| Element | Placement | Purpose |
|---|---|---|
| Primary CTA | Hero + sticky nav + end | Drive main action |
| Social proof | Below hero | Build trust |
| Feature grid | Middle | Show value |
| Testimonials | After features | Validate claims |
| FAQ | Before final CTA | Remove objections |
| Exit intent | Footer | Capture leaving users |

## Color Psychology

- **Blue**: Trust, professional (SaaS, finance)
- **Green**: Growth, health, money
- **Red**: Urgency, excitement (sales, food)
- **Purple**: Premium, creative
- **Black/White**: Luxury, minimal

## Copywriting Framework

Use PAS or AIDA:

**PAS**: Problem → Agitate → Solution
**AIDA**: Attention → Interest → Desire → Action

## Technical Requirements

- Responsive (mobile, tablet, desktop)
- Lighthouse score > 90
- Semantic HTML
- Accessible (WCAG 2.1 AA)
- SEO meta tags + Open Graph
- Analytics tracking
- Form validation
- Loading states
