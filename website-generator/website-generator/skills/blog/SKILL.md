# Skill: Blog / Content Site

## Purpose
Generate content-focused sites optimized for reading and SEO.

## Structure

```
/
├── Home (latest posts, categories)
├── /blog
├── /blog/[slug] (article)
├── /category/[slug]
├── /author/[slug]
├── /about
├── /newsletter
└── /search
```

## Article Template

- Title + subtitle
- Author + date + read time
- Table of contents
- Featured image
- Content (headings, code blocks, images, quotes)
- Author bio
- Related posts
- Comments (optional)
- Social sharing

## SEO Essentials

- Semantic HTML (article, section, nav)
- Schema markup (Article, BreadcrumbList)
- Open Graph + Twitter Cards per post
- Sitemap.xml + robots.txt
- Canonical URLs
- Internal linking
- Reading time estimate
- Table of contents

## Performance

- Static generation (SSG) preferred
- Image optimization (WebP, lazy loading)
- Code syntax highlighting
- Font optimization (self-hosted)
- Pagination or infinite scroll
- Search functionality
