## How to Use This Catalog

1. Find the animation you need by scanning categories above
2. Run the scraper: `node integrations/motion/scraper.mjs <slug>`
3. Or visit: `https://motion.dev/examples/<slug>`
4. Copy the code into your project
5. Customize colors, timing, and content to match the brand
