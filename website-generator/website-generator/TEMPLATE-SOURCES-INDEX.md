## 🚀 INTEGRATION WITH website-generator

Now that you know where templates are, let me show you how to integrate them:

### Step 1: Find Template
```bash
# Search GitHub or StarterIndex
# Example: Looking for SaaS templates in Next.js
github.com/topics/saas-template
starterindex.com/nextjs+saas-boilerplates
```

### Step 2: Add to website-generator
```bash
# Clone into website-generator/templates-integrated/
cd website-generator/templates-integrated/

# Clone template
git clone [template-repo-url] [template-name]

# Or copy manually
cp -r /path/to/template ./[niche]-[template-name]
```

### Step 3: Create Reference Document
```bash
# Create TEMPLATE-DETAILS.md
cat > templates-integrated/[template-name]/TEMPLATE-DETAILS.md << EOF
# [Template Name]

**Niche:** [SaaS/E-commerce/Blog/etc.]
**Framework:** [Next.js/React/Astro/etc.]
**Type:** [Landing/Dashboard/Shop/etc.]
**Best For:** [Description]
**Features:** [List]
**Source:** [GitHub URL]
**License:** [License type]

## Quick Start
npm install
npm run dev

## Customization Guide
[Notes on customization]
EOF
```

### Step 4: Document in Master Index
```bash
# Add to TEMPLATES-INDEX.md
- [Template Name] | [Niche] | [Framework] | templates-integrated/[name]/ | [Description]
```
